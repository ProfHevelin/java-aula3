# Sistema Bancário em Java

Projeto desenvolvido para praticar **Programação Orientada a Objetos (POO)** utilizando Java.

## Funcionalidades

- Cadastro de clientes e gerentes.
- Consulta de saldo.
- Depósito e saque.
- Utilização de herança entre classes.

## Conceitos praticados

- Classes e objetos.
- Atributos e métodos.
- Construtores.
- Herança (`extends`).
- Sobrescrita de métodos (`@Override`).

## Estrutura do projeto

- `Pessoa.java`: classe base.
- `Cliente.java`: classe de cliente.
- `Gerente.java`: classe de gerente.
- `Main.java`: execução do programa.

## Como executar

Abra o projeto no VS Code, execute o arquivo `Main.java` e acompanhe os resultados no terminal.

Projeto desenvolvido para fins educacionais.
